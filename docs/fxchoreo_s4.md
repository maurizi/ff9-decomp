# Choreography literals, slice 4 (fx_0f3 .. fx_128)

The effect modules fx_0f3 .. fx_128 (the late party abilities, Madeen, Odin, Ifrit, the Throw modules, the items
and the enemy skills between them), named per docs/fxdata.md "Choreography literals (pilot)". Each header has a
`/* fx_XXX choreography */` block after its effect-data names. Counts: `python3 tools/fxlits.py <module>`
(actionable literals: compare / mask / case / arg / assign).

## Notes

- **abr pass first**: every literal abr argument of btlfx_drawScreenTint / drawParticles / drawRings / drawTrail /
  addPrimAbr / linkPrimAbr / Hi_ModifyEffModelAbr / Hi_ModifySummonModelAbr in the slice is a `BTLFX_ABR_*` name
  (93 sites, one script over all 48 modules), plus the modules' own abr parameters (fx_0f5's tube helper,
  fx_123's fxm_tintScreenLerp).
- **Prefixes**: the effect-data prefixes. Twins share names with their own values: Eat / Cook (fx_0fe / fx_0ff,
  FX_EAT_ / FX_COOK_ with the same suffixes), the nine Throw modules (FX_THROW_FLIGHT_FRAMES 8 or 6,
  FX_THROW_AFTERIMAGES 4 / 3 / 2, FX_THROW_AFTERIMAGE_DIM 16 / 20; generated by one script), the seven one-emitter
  item modules (FX_<ITEM>_FRAMES), Madeen's two groups (FX_MADEEN_ROCK_COUNT 0x32 / 0x30). fx_112 (enemy Eat) uses
  FX_EAT_ like fx_0fe (the player Eat); the names do not collide inside a module.
- **Countdown slots / fields**: fx_0fa's `timers0[]` slots are FX_DETECT_T_RISE / _SINK / _SPHERE / _FLASH /
  _FLICKER / _AIM with the lengths written into them; fx_105's countdown fields (timer4 .. timer30) got the
  lengths (FX_ODIN_MOON_FRAMES, _NIGHT_FRAMES, _CUT_FRAMES, ...) and the frames that start them.
- **Derived values** written as expressions: Stellar Circle 5's 72-frame drift (`OPEN + WIDEN + SWELL + FADE`) and
  its prim buffer split (`2 * CYL_SEGMENTS` gouraud, `(CYL_RINGS - 2) * CYL_SEGMENTS` flat), Trance's bolt pool
  (`BOLT_COUNT * BOLT_POINTS` = 0x60) and `BOLT_POINTS - 1`, enemy Eat's 28-frame wobble (`GRAB_FRAMES -
  VANISH_FRAME`), Poly's end (`SHRINK_FRAME + SHRINK_FRAMES`), Dragon Breath's draw window (`FADE_OUT_FRAME +
  FADE_OUT_FRAMES`) and model slots (`2 + SLICES`), Madeen's pull-back / glow ramps (`APPEAR_FRAMES -
  PULLBACK_FRAME`, `CHARGE_FRAMES - GLOW_FRAME`), Raining Swords' ring hold (`RING_END_FRAME - RING_FRAME`) and
  shot keys (`SHOT_DELAY + SHOT_FLY_FRAMES`), Odin's and Ifrit's "frame after the shot" motion keys (`SHOT2_FRAME
  + 1`), Eat / Cook's orbit angle step (`0x1000 / ORBIT_COUNT`).
- **Model textures**: every `Hi_RegisterTexEffModel` with literal args got `_TPAGE / _CLUT / _U / _V` (the comment
  decodes page, depth, abr and CLUT position); shared textures share one set (FX_THROW_AFTERIMAGE_*, FX_IFRIT_FLAME_*
  for three models, FX_RAINING_SWORDS_SWORD_* for two, FX_MADEEN_RAINBOW_* for four). `build/texcheck.py`-style
  check through fxdata.py's lit(): all resolve except fx_125's two display-buffer pages (tp1 / tp2, computed,
  unresolved before as well); fx_0fa's METAL_SPHERE render checked by eye (textured).
- **VRAM rects** checked against the sampling model's tpage + u/v: Detect's sphere (page 0xFA at u, v 0x80 ->
  (0x2C0, 0x180, 0x40, 0x40)), Stellar Circle 5's two tubes (8-bit 0x97 -> (0x1C0, 0x100, 0x40, 0x80); 4-bit 0x17
  at v 0x80 -> (0x1C0, 0x180, 0x20, 0x80)), Ifrit's flame page (0x9A -> (0x280, 0x100, 0x40, 0x80)), Trance's aura
  (0xB7: x matches u 0 .. 0x3F, y = v 0x20 .. 0x5F). Not checked: Stellar Circle 5's third rect (0x280, 0x100),
  presumably CLOUD_DOME's texture ('so' model).
- **Sizes**: every `*args` / `workSize` / `elemSize` is `sizeof`. Padded to the op's size: Fx100Work80 (+8),
  Fx104Work80 (+8), Fx0fb0Rock (+4, 0x28). Array bounds from the names (trail buffers `[SLOTS * STRIDE]`, the
  orbit / burst / spawn / sword tables, fx_123's `[FX_RAINING_SWORDS_COUNT]` arrays).
- **GPU words**: `PRIM_TAG(POLY_FT4 / POLY_G4 / POLY_GT4 / DR_TPAGE)` in fx_0f5, fx_0fb_0, fx_0fb_1, fx_105,
  fx_114; `GPU_POLY_FT4 / GT4 | GPU_ABE` and `BTLFX_ABR_OPAQUE` in fx_0f5's tube helper; `SCREEN_W` for the
  full-width bands (fx_105) and the other display buffer (fx_125).
- **Kept numeric** (per the scheme): otZ biases, random spreads, angle / fixed-point math and easing, one-off
  scales and offsets, bone ids (Hi_GetSummonBonePos, btlfx_getUnitBonePos), unit / target indices, sound entries,
  camera-key track numbers, fxm_easeBlend4's mode cases, drawScreenGrid / drawRippleGrid arguments, the
  per-module scroll speeds.
- **Open**: fx_0fb_1's op80 states (seven, lengths 0x1C / 22 / 24 / 37 / 10 / 0x40 / 0x10) and the effect keys
  inside fx_0fb_0's states; fx_114 op80's effect keys between the camera shots and ops 81 .. 83 (rock / shard
  pools); fx_105's ribbon and band helpers' geometry; whether fx_126's registerEffectModel arg 0xFF is an abr.
