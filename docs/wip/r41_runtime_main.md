# R41 main / ovl_0d: literals left for a runtime check

headers already, named by what the code does; each row says what would confirm or correct the part the code can't
prove. Addresses are main-exe addresses (always resident) unless the binary says ovl_0d (resident during Tetra
Master, loaded at 0x800A7000). States: `docs/emulator.md`; `tools/rt/enter_tm.py OPPONENT FRAMES` starts a match
from a paused field state, `tools/rt/vram.lua` dumps VRAM, `tools/rt/tmdump.py` decodes the TmState.
