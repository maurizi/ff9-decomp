# R30 main exe: placeholders left for a runtime check

Naming round R30 for the boot exe (`main`) applied only names the code proves (`docs/wip/names_r30_main.txt`).
The rows below are plausible but unproven, or have no reader in C at all. Each says what to run with `tools/emu.py`
(or the DuckStation MCP) and which state reaches the code (`docs/emulator.md`). Addresses are main-exe addresses,
always resident. GameData fields are relative to `g_gameState->gameData` (read the pointer at `g_gameState`
0x8006794C, then `+4` for `gameData`).
