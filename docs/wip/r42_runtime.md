# R42: runtime questions left by the last naming pass

Round R42 named the last 19 placeholder globals of the boot exe (PsyQ library data and strings, by code and string
evidence) and went through the 174 struct fields still called `unkXX`. Almost all of those fields have no reader in
any binary, so the code gives them no meaning. The rows below are the cheap checks that could still turn up a reader
or a meaning. Each says what to watch or poke and which state reaches the code (`docs/emulator.md`). Questions that
earlier rounds already list (GameData `unk9`/`unk836`/`unk849`/`unk8CC`, `g_menu.unk3`/`unk4`) are in
`docs/wip/r30_runtime_main.md` rows 3 and 5 and aren't repeated here.
