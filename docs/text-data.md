# Data inside `.text`

A port that never executes the PS1's MIPS code can reuse the RAM an overlay's code occupies, except for the
bytes the game reads or writes as data. This page lists those bytes for every binary (the boot exe, the 19
code overlays and the 380 battle effect modules). Everything else in a `.text` range is code.

The table is generated by `tools/docker.sh python3 tools/text_data.py --md docs/text-data.md` (rerun it after
splitting more data out). The tool scans each built binary's disassembly for `%hi`/`%lo` address pairs that
land in `.text` and follows them to the loads and stores that use them, and lists the `textbin` subsegments
of the yamls.

- **Overlays:** only ovl_0b keeps data in `.text`, all of it in its hand-written asm module (`btlbg_asm*.c`)
  and the reciprocal-square-root table after it. All three ranges are `textbin` subsegments in
  `config/ovl_0b.yaml`, so the `c` subsegments of every overlay are exactly the bytes nothing reads.
  `g_btlbgBrightness` and `g_btlbgOtShift` are written at run time, so a port needs them in writable memory
  with their initial values (0x80 and 0).
- **Effect modules:** none. (fx_194's `func_801E77DC` forms 0x801E7CE0 inside its code, but only as the base
  of `&D_801E7D78[frame - 0x13]`; the words it reads are in `.data`.)
- **Boot exe:** only PsyQ library code (libapi/libcard in `psyq_80016BB8.c`). `_patch_gte`, `_patch_card`,
  `_patch_card2`, `_copy_memcard_patch` and `_ExitCard` compare or copy MIPS instruction templates into the
  BIOS's tables and handlers. These are instructions used as data. A port replaces these library calls anyway.
- **Not data:** about 180 places take the address of code without reading it (callbacks stored in function
  pointers, `math_sin`'s and `msg_renderText`'s computed jumps, the event-expression module's handler
  pointers). `tools/text_data.py --code` lists them.

The scan can't follow an address that the code computes some other way (no instance is known). A range can
be confirmed at run time with `tools/emu.py watch`.
